Setup Guide

Step 1 — Get a Free AI Key

Choose a provider below and create an API key:

  • Groq
    console.groq.com → Sign up → Create API Key → Copy it.
  • Gemini
    aistudio.google.com/app/apikey → Sign in → Create API Key → Copy it.

Paste the key in AI Provider → API Key, then click Save API Key.

Step 2 — Connect GitHub

GitHub connection lets GrindWise save accepted solutions into one of your repositories.

  1. Go to GitHub Developer Settings .
  2. Open OAuth Apps and choose New OAuth App.
  3. Use the callback URL shown in the GitHub section.
  4. Copy the Client ID and Client Secret.
  5. Paste the Client ID, then select Connect GitHub.

Step 3 — Pick a Repository

After connecting, select a repository and click Save Repository.

Accepted solutions can then be saved like: solutions/leetcode/two-sum.md.
